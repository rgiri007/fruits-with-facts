# Fruits with Facts

Setup instructions and project documentation.

This repository provides automated video generation based on fruit facts.

## Setup Instructions

1. Clone the repository:
   ```bash
   git clone https://github.com/rgiri007/fruits-with-facts.git
   ```
2. Navigate to the directory:
   ```bash
   cd fruits-with-facts
   ```
3. Install the requirements:
   ```bash
   pip install -r requirements.txt
   ```
4. Configure your API keys for Claude, Hugging Face, and YouTube
5. Follow usage instructions in each script.

## Note
Ensure you have the appropriate API keys and permissions for the Claude, Hugging Face and YouTube APIs.
